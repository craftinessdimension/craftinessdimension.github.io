# craftinessdimension.github.io
​

This is the Blocksuit Engine, a handy tool for MultiCraft that is used to replace a texture of any armour piece of your choice into whatever available block you want.



A "Blocksuit" is a made-up word, which literally refers to a one-piece clothing that makes your player skin covered in a block texture. 

​

With this generator, you can choose any helmet, chestplate, leggings or boots as the base item to retexture.



Then, you can find a block to take the texture of and put it on your previously chosen armour piece, from a list of 57 available items. More will be coming soon after the beta-testing is done.

​

Unfortunately, there will still be bugs here and there, since this is in beta-testing, if that wasn't already obvious. Feel free to check out even more resources, all stored in one particular site by this website's creator.
